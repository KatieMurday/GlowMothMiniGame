# Glow Moth

A tiny browser game. Guide a moth to glowing orbs while dodging drifting storm clouds. The storm gets faster the more light you collect.

**Controls:** mouse or touch to steer, or arrow keys / WASD.

## Run it

Open `index.html` in any browser. No build step or dependencies.

## Host it free

In the repo's **Settings → Pages**, choose the `main` branch and `/ (root)`. The game will be live at `https://<your-username>.github.io/glow-moth/`.
